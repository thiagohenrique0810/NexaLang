A Linguagem Universal de Sistemas - Combinando segurança moderna com poder de baixo nível

🚀 Introdução

NexaLang é uma linguagem de programação de sistemas moderna e de alta performance, projetada para unificar computação CPU e GPU. Ela combina a segurança de linguagens modernas com o poder bruto de controle de baixo nível, tudo sem um coletor de lixo.

🧠 Gerenciamento Híbrido de Memória

Seguro por padrão, manual quando necessário. NexaLang usa Affine Ownership para prevenir vazamentos e data races em tempo de compilação, mas permite gerenciamento baseado em Regions e blocos unsafe para drivers de hardware.

⚡ Kernels GPU Nativos

Pare de escrever strings CUDA C++ no seu código. NexaLang trata a GPU como cidadão de primeira classe. Escreva kernels diretamente na sintaxe padrão NexaLang e dispare-os perfeitamente.

🔌 Interop Zero-Cost

Ligue diretamente com bibliotecas C e C++ sem overhead. Gere bindings Python e JavaScript automaticamente com a toolchain nx.

Filosofia

"Control by Choice, Safety by Default"

NexaLang oferece controle total quando você precisa, mas segurança por padrão. Você pode optar por usar blocos unsafe quando necessário, mas o compilador garante que você está ciente dos riscos.

🛠️ Instalação Global

NexaLang agora conta com um comando CLI unificado para facilitar o desenvolvimento.

Requisitos

  • LLVM / Clang (v15+ recomendado)
  • Python 3.8+ (para o gerenciador de build)

Configuração no Windows

  1. Abra as Variáveis de Ambiente do sistema.
  2. Adicione o caminho da pasta raiz do NexaLang ao seu Path de usuário.
  3. Reinicie o terminal.

Configuração no Linux / macOS

# Na pasta do projeto
chmod +x nxc
sudo ln -s $(pwd)/nxc /usr/local/bin/nxc

Uso da CLI

# Inicializar um novo projeto
nxpkg init meu_projeto

# Compilar e executar um arquivo
nxc run examples/hello.nxl

# Compilar para binário nativo otimizado
nxc build main.nxl --opt O3 --out artifacts/build/bin/meu_programa

# Rodar todos os testes unitários
nxc test meu_codigo.nxl

Métodos (impl blocks)

struct Vector {
    x: i32,
    y: i32
}

impl Vector {
    # Método estático
    fn new(x: i32, y: i32) -> Vector {
        return Vector(x, y)
    }
    
    # Método de instância (referência imutável)
    fn dot(&self, other: Vector) -> i32 {
        let a = self.x * other.x
        let b = self.y * other.y
        return a + b
    }
}

fn main() {
    let v1 = Vector::new(10, 20)
    let v2 = Vector::new(3, 4)
    let prod = v1.dot(v2)  # Método de instância
}

🔒 Ownership & Borrowing

NexaLang usa um sistema de Affine Ownership similar ao Rust. Por padrão, tipos não-Copy são movidos quando atribuídos ou passados como argumentos.

Move Semântics

struct Foo {
    x: i32
}

fn take(foo: Foo) {
    print(foo.x)
}

fn main() {
    let f: Foo = Foo(123)
    take(f)        # move - ownership transferido
    print(f.x)     # ERRO: use after move
}

Borrowing (Empréstimo)

# Borrow imutável (&T)
fn read(foo: &Foo) {
    print(foo.x)  # Apenas leitura
}

# Borrow mutável (&mut T)
fn modify(foo: &mut Foo) {
    foo.x = 999  # Modificação permitida
}

fn main() {
    let mut f = Foo(123)
    read(&f)           # Múltiplos borrows imutáveis OK
    modify(&mut f)    # Apenas um borrow mutável por vez
}
Regras de Borrowing:
  • Múltiplos borrows imutáveis são permitidos simultaneamente
  • Apenas um borrow mutável por vez
  • Não é possível ter borrow mutável e imutável ao mesmo tempo

🗂️ Regions (Arenas)

Regions permitem gerenciamento de memória baseado em arenas. Toda a memória alocada em uma região é liberada quando a região sai de escopo. 

fn process_transaction() {
    region temp_arena {
        let user = User::new(in temp_arena)
        let cart = Cart::new(in temp_arena)
        # ... processamento pesado ...
    }  # temp_arena dropped aqui - desalocação O(1) instantânea
}
Vantagem: Desalocação em O(1) - toda a memória da arena é liberada de uma vez.

🎮 GPU Kernels

Uma das features principais do NexaLang é tratar a GPU como um contexto de execução padrão. Você pode escrever kernels diretamente em NexaLang usando a palavra-chave kernel.

Definição de Kernel

kernel fn compute_physics(particles: Buffer<Particle>) {
    let i = gpu::global_id().x
    # Lógica executa na GPU
    particles[i].velocity = particles[i].velocity * 0.99
}

Dispatch de Kernel

fn main() {
    let particles = load_particles()
    # Dispara kernel na GPU
    gpu::dispatch(compute_physics, args: (particles,), threads: 1024)
}

SPIR-V Backend

O compilador pode gerar código SPIR-V para execução em GPUs compatíveis:

python bootstrap/main.py examples/gpu_kernel.nxl --target spirv --emit spv --out artifacts/build/kernel.spv
Suporte Vulkan: O compilador suporta ambiente Vulkan com --spirv-env vulkan.

🧪 Metaprogramação & Testes

Atributos

NexaLang utiliza atributos @[nome] para anexar metadados e comportamentos especiais a funções e estruturas.

Testes Unitários

Marque funções com @[test] para incluí-las no runner de testes integrado.

@[test]
fn test_soma() {
    assert(1 + 1 == 2, "Erro na soma")
}

Derivação Automática

Use @[derive(Debug)] para gerar automaticamente métodos úteis, como o debug_print().

@[derive(Debug)]
struct Point { x: i32, y: i32 }

fn main() {
    let p = Point(10, 20)
    p.debug_print() # Saída: Point { x: 10, y: 20 }
}

Exemplo 2: Struct com Métodos

struct Point {
    x: i32,
    y: i32
}

impl Point {
    fn new(x: i32, y: i32) -> Point {
        return Point(x, y)
    }
    
    fn distance(&self, other: &Point) -> f32 {
        let dx = self.x - other.x
        let dy = self.y - other.y
        # Cálculo simplificado
        return cast::<f32>(dx * dx + dy * dy)
    }
}

fn main() {
    let p1 = Point::new(0, 0)
    let p2 = Point::new(3, 4)
    print(p1.distance(&p2))
}
